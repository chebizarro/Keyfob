## Problem
iOS ConsentCoordinator calls PolicyEngine.shared.startSession() after Mode B biometric auth. macOS MacConsentCoordinator does not, only sets approved = true.

## Evidence
iOS ConsentCoordinator.swift:45-47 has startSession call. MacConsentCoordinator.swift:39-42 is missing it.

## Affected Files
- Apps/Keyfob-macOS/MacConsentCoordinator.swift

## Fix Strategy
Add PolicyEngine.shared.startSession() call after successful biometric auth in Mode B, matching iOS behavior.
